# ADR-0001: 가벼운 Phase 0 — 얇은 감독 프로그램으로 시작

- 상태: 채택 (2026-09-28)
- 결정한 사람: CEO
- 근거 문서: GPT-6 Pro 실행 기획서 v2 (구독 전용), Claude 교차 검토

## 결정

GPT 기획서 v2의 원칙(API 키 없음, 공식 CLI 본인 로그인, 증거 기반 완료, 신뢰 테스트 분리,
CEO 결재, Godot 작은 게임)은 그대로 따른다. 다만 감독 프로그램은 파이썬 표준 라이브러리만 쓰는
얇은 형태로 시작하고, 무인 운영용 방어 장치는 무인 운영을 켜기 직전에 만든다.

## 바로 만든 것

- 작업 카드·기록은 파일 (`data/`), 규칙은 `company/`, 검증은 `trusted/`
- 작업별 git worktree, 허용 경로 밖 변경 자동 되돌림, 후보 커밋 고정
- 신뢰 검증: 후보 커밋 스냅샷 + 작업자가 못 바꾸는 테스트, 테스트 수 확인
- Codex(기획·개발·리서치) / Claude Code(리뷰, 교차 모델) / 실패 시 Codex 별도 세션 리뷰
- 긴급 정지(프로세스 트리 종료), 재시작 시 fail-closed 복구, 하루 실행 상한
- 로컬 대시보드 (127.0.0.1, 세션 토큰, Host 검사)

## 미룬 것과 다시 볼 조건

| 미룬 것 | 다시 볼 조건 |
|---|---|
| 별도 Windows 계정 QA 실행기, 네트워크 차단 | 무인 운영(자리 비운 채 병합)을 켜기 전 |
| 이벤트 재생 기반 크래시 복구 | 재시작 후 복구 실패가 실제로 발생하면 |
| 메신저(텔레그램 등) 접수·알림 | 자리 비운 동안 결재가 주 3회 이상 밀리면 |
| 동시 실행 2개 이상 | '순서 대기' 시간이 실제 병목으로 측정되면 |
| 픽셀 오피스 화면 | 흐름이 30작업 이상 안정된 뒤 |
| Codex Bot | 공식 출시 후, 같은 작업 10개를 기존 흐름과 나란히 돌려 비교한 뒤 |

## 알려진 한계

- Codex `workspace-write` 샌드박스는 작업 폴더 밖 쓰기를 막지만 임시 폴더(%TEMP%) 쓰기는 허용한다.
- Claude Pro 플랜은 CEO의 대화 사용량과 리뷰가 같은 한도를 쓴다. 리뷰 프롬프트는 diff 중심으로 짧게 유지한다.
- 같은 프로젝트에서는 결재가 끝나야 다음 작업이 시작된다 (병합 충돌을 원천 차단하는 대신 느리다).
