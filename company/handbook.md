# AI Studio 운영 안내서

CEO(사람 1명)가 지시하고 결재하며, AI 직원들이 기획·개발·리뷰·리서치를 합니다.
회사 규칙과 기록은 모두 이 저장소의 파일이고, 감독 프로그램(`studio.py`)은 그 파일대로 일을 돌립니다.

## 조직

| 직원 | 실행기 | 권한 | 하는 일 |
|---|---|---|---|
| 기획 담당 | Codex · GPT-6 Luna | 읽기 전용 | 지시를 작업 카드(최대 8개)로 나눔 |
| 개발 담당 | Codex · GPT-6 Sol | 작업 폴더 쓰기 | 작업 카드 하나를 구현 |
| 리뷰 담당 | Claude Code (안 되면 Codex 별도 세션) | 읽기 전용 | 변경 내용 검토 |
| 리서치·문서 담당 | Codex · GPT-6 Luna | 작업 폴더 쓰기 | 출처 달린 보고서 작성 |

직원 4명은 프로세스 4개가 아닙니다. 한 번에 하나씩, 역할별 규칙과 권한으로 실행됩니다.
모델과 권한은 `studio.toml`의 `[roles.*]`에서 바꿉니다.

## 일의 흐름

```
CEO 지시 ─▶ 기획 담당 ─▶ [결재] 기획안 승인 ─▶ 작업 카드(준비)
                                                   │
      ┌────────────────────────────────────────────┘
      ▼
 개발 담당 (작업별 git worktree, 허용 경로만)
      │  범위 밖 변경은 자동으로 되돌림
      ▼
 신뢰 검증 (후보 커밋 스냅샷 + trusted/ 테스트, 작업자는 못 바꿈)
      │  실패 → 피드백 붙여 1회 재시도 → 또 실패면 '막힘'
      ▼
 리뷰 담당 (다른 모델, 읽기 전용)
      │  수정 요청 → 1회 재시도
      ▼
 [결재] CEO 승인 ─▶ 검증한 그 커밋만 main에 병합 ─▶ 완료
```

## 상태

| 상태 | 뜻 | CEO가 할 수 있는 것 |
|---|---|---|
| 기획 대기 | 기획 담당 차례를 기다림 | 취소 |
| 준비 | 실행할 수 있음 | 실행, 취소 |
| 작업 중 / 검증 중 | 에이전트나 테스트가 도는 중 | 취소, 긴급 정지 |
| 결재 대기 | 검증·리뷰 통과, 승인 기다림 | 승인(병합), 수정 요청, 취소 |
| 막힘 | 한도·로그인·반복 실패 등으로 멈춤 | 원인 확인 후 재시도, 취소 |
| 완료 | 병합됨 | — |

## 관문 (거짓 완료 막기)

1. **범위:** 작업 카드의 `allowed_paths` 밖이나 보호 경로를 바꾸면 되돌린다.
2. **신뢰 검증:** 후보 커밋을 깨끗한 폴더로 꺼내 `trusted/`의 테스트로 검사한다. 테스트 수가 모자라거나, 건너뛰었거나, 결과 파일이 없으면 실패다.
3. **리뷰:** 작성자와 다른 모델이 읽기 전용으로 검토한다. Codex로 대신하면 "교차 검증 아님"으로 표시한다.
4. **결재:** 검증 결과의 커밋과 후보 커밋이 같아야만 병합한다. 결재 사이 main이 바뀌면 병합하지 않는다.

## CEO만 하는 일

- 지시와 기획안 승인, 병합 승인
- 게임의 재미, 아트 방향, 출시 결정 (에이전트 점수로 대신하지 않음)
- 신뢰 테스트(`trusted/`)와 회사 규칙(`company/`) 변경
- 외부 게시, 결제, 계정, 추가 구독 — 이 시스템은 하지 않습니다

## 한도와 멈춤

- 동시 실행 1개, 작업당 개발 시도 2회(초안 + 수정 1회), 실행 1회 20분
- 하루 안전망: 에이전트 실행 40회, 240분 (`studio.toml [limits]`)
- 구독 사용 한도 메시지가 오면 회사를 자동 정지합니다. API로 우회하지 않습니다.
- **긴급 정지:** 대시보드 오른쪽 위 버튼. 실행 중인 에이전트와 자식 프로세스를 모두 끄고, 그 작업은 '막힘'이 됩니다.
- 감독 프로그램이 비정상 종료되면, 다시 켤 때 '작업 중'이던 카드는 막힘으로 돌립니다 (자동으로 다시 부르지 않음).

## 새 프로젝트 추가

1. `projects/<이름>/`에 폴더를 만들고 `AGENTS.md`, `README.md`를 둡니다.
2. `trusted/projects/<이름>.toml`에 저장소 경로와 검증 명령을 적습니다.
3. 검증 테스트가 있으면 `trusted/acceptance/<이름>/`에 둡니다.
4. `python studio.py init` → 저장소가 만들어집니다.
