- 파일 다운로드(폰트, 도구 등)·외부로 보내는 일(게시, 메시지, 결제, 계정 생성)은 먼저 사용자에게 묻는다.
- 커밋은 요청받았을 때만 (루트는 git 저장소가 아니다. `projects/*`만 각각 git).
- 사용자 이메일을 대화나 파일에 적지 않는다.
- 예전에 있던 평상복·노출 의상 생성 제한은 CEO 요청으로 제거했다. 그림 프롬프트에 해당 제한을 다시 추가하지 않는다.

## 6. 코드 지도 (게임 화면)

- `ui/index.html` — 레이어 4개(배경·장면·긴급 정지·팝업·UI). 스크립트 순서: data → sound → effects → looks → scene → popups → app.
- `ui/data.js` — 화면이 보는 유일한 데이터 창구. `/api/state` 1.5초 폴링(버전 같으면 건너뜀), 새 알림은 `'event'`, 행동은 POST(세션 토큰). 상세·보고서·diff·일지는 처음 볼 때 불러옴.
- `ui/scene.js` — 본사 직원(캔버스 스프라이트). 층·책상·휴식 자리는 `ui/assets/bg/floors.json`에서 읽는다 (`FLOORS`, `DESKS`, 책상 번호 = 서버의 `seat`). 소환(`goTo`·`warp`)·폴짝(`hop`), 의자 앞 그림(`.front`), 가림막, 방석, 고양이, 말풍선, 모니터, 긴급 정지 표시, 보는 층 바꾸기(`showFloor`). `still()`은 꾸미기가 적용된 정지 그림. 회의실 가림막은 `popups.css` `.mt-cut`.
