# 공개본 인수인계 — 2026-10-07

이 문서는 공개 소스의 구성과 재검증 방법을 요약합니다. 로컬 회사의 작업 ID·연결 주소·연결 번호·실행 기록·개인 경로는 포함하지 않습니다.

## 현재 프로그램

- 모던 홈·칸반/목록 진행판·빠른 찾기·주간 요약을 사용합니다. 도트 사무실 코드/그림을 제거했고 오른쪽 발표 캐릭터는 기본 화면에서 생성하거나 로드하지 않습니다. 직원 얼굴·꾸미기는 별도 기능으로 유지합니다.
- 이미지·영상 작업대, 소설 집필실, 디자인 작업실, 모바일 화면을 제공합니다. 자세한 화면 기준은 `docs/design/modern-ui.md`입니다.
- 프로젝트 등록과 작업 대상 변경, 실행 단계 저장·불확실한 쓰기의 안전한 중단, 제한된 병렬 실행과 작업별 취소를 유지합니다.
- Grok 미디어 연결은 공식 CLI의 기존 로그인과 명시적 도구 제한을 사용합니다. 연결 설정과 개별 미디어 작업 승인이 필요하며 제3자 고정 스크립트 실행 경로는 차단 상태입니다.
- 외부 OAuth MCP 게이트웨이는 기본 꺼짐입니다. 프로젝트별 읽기·제출·실행 권한, 자신이 맡긴 작업만 실행, 동시 시작 상한, 긴급 정지를 적용합니다. CEO 승인·병합을 우회하지 않습니다.
- 리뷰어가 제시한 근거 파일은 감독 프로그램이 허용 범위·검증 사본·실제 파일 존재를 확인한 뒤 누락된 근거만 보완합니다. 기존 명시 근거를 덮어쓰거나 출처를 만들지 않습니다.

## 개발 및 검증

1. `AGENTS.md`와 관련 모듈을 먼저 읽습니다. Python 표준 라이브러리와 CSP·문자열 안전 출력 규칙을 유지합니다.
2. `python -X utf8 -B tools/dev/regression.py --report reports/regression.json`을 실행합니다.
3. `python -X utf8 -B tools/dev/supervisor_smoke.py --report reports/supervisor-fake.json`으로 임시 회사의 MCP를 검사합니다.
4. 실제 화면 검사는 `tools/dev/*_browser.cjs`와 `office_gone_check.cjs`를 사용합니다. 기존 Playwright 설치 위치를 `PLAYWRIGHT_CORE`로 전달하거나 개발 환경에서 모듈을 설치해야 합니다. 테스트 서버는 임시 회사와 가짜 실행기만 사용합니다.

이번 공개본의 검사 결과는 `docs/verification/release-20261007.md`를 확인하세요. 새로운 로그인·실제 모델 호출·공개 터널 활성화는 이 소스 검증에 포함하지 않습니다. 로컬 사용자 상태는 저장소에 포함되지 않습니다.
