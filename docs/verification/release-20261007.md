## 업로드 검토 중 수정

OAuth 새로고침 요청이 권한을 읽기만으로 줄여도 실제 토큰 검사가 원래 연결 범위를 쓰는 문제를 재현했다. 토큰별 scope 저장과 검사로 수정했고, 축소된 토큰의 제출·실행 도구 차단·직접 호출 차단·다시 읽은 뒤의 유지까지 회귀 검사했다. 이 새 검사는 위 최종 전체 검사에 포함돼 있다. 수정 전 전체 검사 시도는 중단했고 결과로 세지 않았다.

개인 설치 경로를 개발용 브라우저 도구에서 제거했고, 공개 인수인계는 프로그램 구조와 검증 절차만 남겼다. 런타임·브라우저 추적·개인 연결 정보·선택적으로 내려받은 제3자 스크립트는 업로드하지 않는다. 공개 파일은 비밀정보 패턴과 경로 기준으로 검사했다.
