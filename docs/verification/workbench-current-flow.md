# 실제 실행 기록에 따른 작업대 전류 효과

`codex/workbench-current-flow-20261005`, 기준 `7ce7adaab0c40d8ac507d974ca36712348677161`.
기능 작업대와 대표 화면의 기존 구현을 보존한 제한된 UI 변경이다. 거절된 별도 3D 폴더 시제품은 보존만 했으며, 폴더의 모양·재질·종이 노드 배치는 바꾸지 않았다. main 병합·push·배포·운영 서버 재시작은 하지 않았다.

## 구현

- 작업대의 `running` 상태만으로 효과를 켜지 않는다. 실제 작업 상태, 일지 단계(`build1` 등/기획/기존 QA/읽기 전용 리뷰), `run_id`, 후보 SHA, 흐름·노드·수정 버전과 시작/작업 연결 기록이 일치해야 해당 모델 노드가 움직인다. 준비/대기/기록 불일치는 정적 표시다.
- 입력이 완료된 실제 실행 노드의 입력선에만 짧은 청록 전류를 표시한다. 향후 테스트·검토·승인 노드는 움직이지 않는다. 구현 작업 안에서 실행되는 QA·리뷰는 구현 카드에 단계명으로 표시하며, 이후 테스트/검토 노드는 기존 근거를 읽는 단계로 유지한다.
- 새 `node_finished` 기록은 완료 효과와 실제 들어오는 선의 전달 효과를 한 번만 표시한다. 중복 이벤트를 제거하고, 처음 열기·재연결·새 수정 버전·그래프 변경·화면 재열기에는 지난 효과를 재생하지 않는다. 같은 조회에서 SVG 그룹을 유지하여 애니메이션이 매번 초기화되지 않는다.
- 승인 대기·근거 누락은 황갈색 정적 표시, 실패는 붉은 갈색, 중단/선행 오류는 회색, 결과 불확실·회사 정지·오프라인은 정적 확인 표시다. 실제 QA 통과와 완료 근거 누락을 구분하고 기존 결재 잠금을 유지한다. 실패 뒤 보조 기술 알림에 이전 ‘실행 중’ 문구가 남지 않는다.
- OS 동작 감소와 기존 효과 끄기 설정에서 이동 전류·광택·완료 반짝임을 숨기고 상태 글자와 표식을 유지한다. 폴링은 표시만 갱신한다. 모델 재호출·자동 재시도·타이머에 의한 업무 진행은 추가하지 않았다.
- 제품 변경은 `ui/workbench.js`, `ui/workbench.css`다. 기존 `TempStudio`/`Engine`/`FakeRuntime`를 사용하는 미리보기 도구에 선택적 임시 촬영 게이트를 추가했다. 별도 실행기나 제품 API를 만들지 않았다.

## 최종 검증

- 기록 판정 검사 41개 통과: 준비/대기, 실제 단계/번호/후보/버전 일치, 불일치·누락, QA와 리뷰 구분, 중복·재연결·수정 버전, 분기, 실패/불확실/중단, 근거 누락.
- 실제 Edge 신규 화면 검사 52개 통과: 원래 배치, 중복 클릭, SVG/애니메이션 위상 유지, 연결 실패·같은 실행 복구, 닫기/재열기, 키보드, 1024/390px, OS 동작 감소와 기존 효과 끄기, 실제 FakeRuntime 후보·QA·리뷰·누락 2/3, GET 응답으로만 재현한 실패/중단/불확실 복구와 알림. 제품 서버 상태를 직접 수정하지 않았다.
- 변경하지 않은 기존 시각 검사 32개와 조작/복구 검사 22개도 통과했다. 새 파일명으로 캡처해 기존 승인 캡처는 보존했다.
- 정상 `unittest discover -s tests -t .`의 358개와 동일한 목록을 모듈별 격리 프로세스로 실행: 357 통과, POSIX 전용 1개 생략, 실패/오류 0, 모든 모듈 종료 0. 수용 기준/테스트를 수정하지 않았다.
- JS 문법/diff 검사 통과. `python studio.py doctor` 종료 0, 기존 Claude 사용 불가 주의만 남았다. 계정/보안 설정 변경은 없었다.

- 실제 모델 호출/운영 제출·취소·쓰기·재시작 0. 보호 파일 1,939개 해시 변경/삭제 0, 기존 미추적 산출물·승인 화면·3D 시제품·백엔드/결재 엔진 보존.

- 이번 새 캡처/영상의 Library 전송은 실행 안 함. 이전 시제품 전송의 공식 `prepare_uploads` 환경 오류를 우회하거나 새 접근 권한을 요청하지 않았다. 로컬 결과물은 위 경로에 보존했다.
