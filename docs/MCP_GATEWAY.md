# MCP 연결 문 (ChatGPT·Dots 같은 바깥 AI 앱이 AI 스튜디오를 쓰게 하기)

> 상태: 코드와 시험은 끝났어요. **진짜 ChatGPT·Dots와 터널로는 아직 한 번도 이어 보지 않았어요** (인터넷·터널을 쓰지 않는 조건으로 만들었어요). 아래 순서는 OpenAI 공식 문서에서 확인한 규격을 그대로 맞춘 것이고, 실제 연결은 사장님이 터널을 켠 뒤에 해 봐야 알 수 있어요.

## 1. 이게 뭐예요?

- AI 스튜디오에는 이미 **'외부 감독 MCP'**가 있어요 (`docs/MCP_SERVER.md`). 바깥 AI가 프로젝트와 일 목록을 보고(`list_projects` `list_tasks`), 일을 맡기고(`submit_task`), 진행과 결과를 보고(`task_status` `task_events` `task_result` `task_artifact`), 자기가 맡긴 일을 취소(`cancel_task`)하고, **사장님이 허용한 프로젝트에서는 실행도 직접 시작시키는(`run_task`)** 도구 9개예요. 결재·병합·완료 도구는 없어요.
- 그런데 그 문은 **이 PC 안(127.0.0.1)에서만** 열리고 감독 토큰이 필요해서, 인터넷에 있는 ChatGPT나 Dots는 못 써요.
- ChatGPT는 API 키·클라이언트 자격(M2M)·사용자 지정 인증서를 지원하지 않고 **OAuth 로그인 또는 인증 없음**만 지원해요. 그래서 이번에 **OAuth 로그인 서버와 보호된 MCP 입구를 한 서버로** 만들었어요. 이 서버가 **'MCP 연결 문(게이트웨이)'**이에요.
- 연결 문은 **기본으로 꺼져 있고**, 켜도 **이 PC의 127.0.0.1에만** 열려요 (포트 8767). 인터넷에 닿게 하는 일(터널)은 **사장님이 따로 켜는 일**이에요. 이 프로그램은 터널을 설치하지도 실행하지도 않고, 바깥으로 먼저 요청을 보내지도 않아요.

## 2. 안전장치

| 장치 | 내용 |
|---|---|
| 기본 꺼짐 | 사장님이 화면에서 켜기 전에는 포트가 열리지 않아요. 끄면 바로 닫혀요. |
| 별도 서버 | 대시보드와 다른 서버예요. 이 서버는 아래 경로만 내고 **나머지는 모두 404**예요: 안내문 `/.well-known/oauth-protected-resource`(+`/mcp`) · `/.well-known/oauth-authorization-server`, `POST /oauth/register`, `GET·POST /oauth/authorize`, `POST /oauth/token`, `POST /mcp`, 동의 화면 CSS. 대시보드 화면·`/api/*`·`/m`(휴대폰)·세션 토큰·휴대폰 토큰은 이 서버에 없어요. CORS도 없어요. |
| 주소 검사 | 사장님이 넣은 공개 주소(`https://…`만)의 이름과 `127.0.0.1`·`localhost`만 받아요. 다른 이름으로 들어오면 거절해요. |
| 연결 번호 | 새 앱이 연결되려면 사장님이 **대시보드에서 [연결 번호 만들기]**를 눌러 나온 번호를 동의 화면에 넣어야 해요. 5분 동안, 한 번만 쓸 수 있고, 5번 틀리면 1분 동안 모든 시도를 막아요 (휴대폰 짝짓기와 같은 방식). 번호 없이는 어떤 코드도 나가지 않아요. |
| 토큰 | 코드·토큰은 무작위 32바이트 이상. 디스크에는 **SHA-256 해시만** 저장하고 로그·화면·오류 글에 값을 내지 않아요. 인증 코드는 60초·한 번·PKCE(S256 필수)·연결 주소와 서버 주소에 묶여요. 액세스 토큰 1시간, 새로고침 토큰 30일(쓸 때마다 바뀌고, 이미 쓴 것이 다시 오면 그 연결 전체를 거둬요). `plain` PKCE·implicit·password·client_credentials는 거절해요. |
| 권한 | 기본은 **읽기만**. 사장님이 '일 맡기기도 허용'을 고르면 **프로젝트마다 단계**를 따로 골라요: **읽기만** · **일 맡기기**(실행은 사장님이 [실행]을 눌러요) · **일 맡기기 + 실행 시작**(앱이 직접 실행을 시작해요, 사용량을 써요). 새로 연 프로젝트는 '읽기만'으로 시작하고 폴더 범위도 프로젝트마다 따로예요. 권한은 매 요청마다 지금 설정과 맞춰 봐서, 줄이면 이미 연결된 앱에도 **바로** 적용돼요 (늘려도 이미 연결된 앱은 그대로이고 다시 연결해야 해요). 기존 외부 감독의 권한 검사(프로젝트별 읽기·쓰기·실행·폴더 범위)를 그대로 써요. |
| 실행 시작 | `run_task`는 아래 2-1의 조건을 **모두** 맞출 때만 돼요. 설정에서 '실행 시작'을 켠 프로젝트가 하나도 없으면 도구 목록에서 아예 사라져요. |
| 결재 | 일의 결재·병합·완료는 **항상 사장님**이에요. 연결한 앱은 결재 도구가 아예 없어요. 실행을 시작시켜도 결과를 확인하고 반영하는 일은 사장님이 해요. 모델 실행·자동 실행 허용도 기존 설정을 따라요. |
| 기록 | 인증 시도·연결 승인·토큰 발급·거절·도구 호출(도구 이름과 결과 종류만, 내용은 안 적어요)·끊기를 `data/gateway/audit.jsonl`에 적고, 중요한 일은 활동 기록에도 남겨요. 화면의 '최근 기록'에서 20줄을 볼 수 있어요. |
| 제한 | 요청 속도 제한(주소별·연결별·인증 실패별), 본문 크기 제한(MCP는 대시보드 MCP와 같은 1MB), 동시 연결 16개 제한, 앱 등록 20개 제한(안 쓴 등록은 자동 정리). |

## 2-1. 실행 시작 (`run_task`): Dots가 직접 시작시키기

맡기기만으로는 일이 시작되지 않아요 (사장님이 화면에서 [실행]을 눌러야 직원이 움직여요). 앱이 주도하는 일에서는 이게 번거로워서, 사장님이 **프로젝트마다 따로 켠 곳에서만** 앱이 [실행]과 같은 일을 대신 시킬 수 있게 했어요. 화면의 [실행]과 같은 길(`Engine.request_run`)을 써서 새 우회로는 없어요.

| 조건 | 안 맞으면 |
|---|---|
| 그 프로젝트가 **'일 맡기기 + 실행 시작'** 단계 | "실행 시작 권한이 없어요. 사장님이 이 프로젝트에서 '실행 시작'을 켜야 해요." |
| **이 앱이 맡긴 일**만 (사장님이 만든 일·다른 앱이 맡긴 일은 안 돼요) | "이 연결이 맡긴 일만 실행을 시작할 수 있어요." |
| 상태가 **대기 중**(기획 대기·준비)일 때만 새로 시작. 이미 시작했거나 일하는 중·검증 중·결재 대기이면 오류 없이 지금 상태만 돌려줘요 (같은 호출을 다시 해도 안전) | 끝난 일·취소한 일은 "이미 끝난 일이라…", 막힌 일은 "막힌 일이라…" (사장님이 막힌 까닭을 확인하고 다시 시도해야 해요) |
| **회사가 긴급 정지 중이 아닐 때** | "회사가 긴급 정지 중이라 실행을 시작할 수 없어요. 사장님이 다시 시작해야 해요." |
| 이 앱이 **동시에 실행을 시작해 둔 일이 3개 미만** (일하는 중·검증 중이거나, 시작을 요청해 두고 기다리는 일. 결재를 기다리는 일은 세지 않아요) | "동시에 실행을 시작한 일이 3개예요. 끝난 뒤에 다시 시도해 주세요." |

- 결과가 나오면 **결재·병합·완료는 사장님**이에요. 앱은 `task_status`·`task_result`로 진행과 결과만 볼 수 있어요.
- 실행은 구독 사용량을 써요. 쓰지 않을 프로젝트는 '일 맡기기'나 '읽기만'으로 두세요. 설정을 줄이면 같은 연결이 바로 못 쓰게 돼요.
- 기록: 도구 호출은 `data/gateway/audit.jsonl`에 도구 이름만(내용 없이), 활동 기록에는 "T0004 외부 연결이 실행을 시작시켰어요"가 남아요.
- 옛 외부 감독 설정(`data/supervisors.json`)에는 `run` 칸이 없어서 **기본 꺼짐**이에요. 켜려면 사장님이 그 프로젝트 권한에 `"run": true`를 직접 넣어야 해요.

## 3. ChatGPT(와 Dots)에 연결하는 순서

Dots는 ChatGPT 안에서도 쓰는 에이전트라서, ChatGPT 쪽 '앱(커넥터)'으로 이 주소를 붙이는 것까지가 확인된 방법이에요. **Dots가 사용자 지정 MCP를 직접 쓸 수 있는지는 OpenAI가 공식 문서에 적어 두지 않아서 미확인이에요.** ChatGPT에서 연결이 되면 Dots가 그 앱을 쓸 수 있는지 Dots 설정에서 따로 확인해 주세요.

1. **터널 준비 (사장님 승인 필요)**: 아래 4번에서 하나를 골라 사장님이 직접 설치·실행해요. 터널이 알려 주는 `https://…` 주소를 적어 두세요. 터널이 연결해 줄 이 PC 쪽 주소는 `http://127.0.0.1:8767` 이에요.
2. AI 스튜디오 왼쪽 메뉴 **'회사' → '외부 연결'**을 열어요.
3. **권한**에서 정해요. 처음에는 '읽기만'으로 두고 열어 줄 프로젝트와 폴더 범위(예: `docs/**`)를 고른 뒤 [권한 저장]. 일을 맡기게 하려면 '일 맡기기도 허용'을 고르면 프로젝트마다 **단계 선택칸**이 생겨요: '읽기만' · '일 맡기기'(실행은 사장님이 [실행]을 눌러요) · '일 맡기기 + 실행 시작'(앱이 직접 시작시켜요, 사용량을 써요). 프로젝트마다 알맞은 단계를 골라 폴더 범위와 함께 저장해요 (새로 연 프로젝트는 '읽기만'으로 시작, 잘못된 범위는 쉬운 글로 알려 줘요). 예: 게임 저장소는 읽기만, 문서 저장소는 `reports/**`에 일 맡기기, 보고서 저장소만 '일 맡기기 + 실행 시작'.
4. **공개 주소** 칸에 터널이 알려 준 주소를 넣고 **[외부 연결 받기] 스위치**를 켜요. 칩이 '켜짐 · 기다리는 중'이 돼요. 주소에는 `https://이름.도메인`만 넣어요 (뒤에 `/mcp` 같은 경로를 붙이지 않아요).
5. **'연결에 붙여 넣을 주소'**의 **[복사]**를 눌러요. `https://…/mcp` 모양이에요.
6. **ChatGPT**에서: 설정 → (앱/커넥터) → 개발자 모드를 켜고 → 새 앱(커넥터·플러그인) 추가 → **MCP 서버 주소**에 위 주소를 붙여 넣고 → 인증 방식은 **OAuth** → 만들기/연결. (메뉴 이름은 ChatGPT 버전에 따라 조금씩 달라요.)
7. 브라우저에 **AI 스튜디오의 동의 화면**이 떠요 (앱 이름·돌아갈 주소·허용할 일이 쉬운 말로 보여요). 이때 AI 스튜디오에서 **[연결 번호 만들기]**를 눌러 나온 번호를 입력하고 [허용하고 연결]을 눌러요. 번호는 5분 안에 한 번만 써요.
8. '연결된 앱'에 이름과 권한이 뜨면 끝이에요. ChatGPT 대화에서 앱을 켜고 "AI 스튜디오의 일 상태 알려 줘"처럼 시켜 보세요.

## 4. 터널 선택지 (설치는 사장님 승인이 있어야 해요)

이 프로그램과 이 문서를 만든 작업자는 아래 도구를 **설치·다운로드·실행하지 않았어요.** 이름·출처는 아래와 같고, 용량과 명령 모양은 이 PC에서 인터넷 확인을 하지 않아서 **미확인**이에요. 설치 전에 공식 안내와 내려받는 파일 크기를 확인해 주세요.

| 이름 | 출처 | 특징 | 명령 예시 (도구 버전에 따라 다를 수 있어요) |
|---|---|---|---|
| Cloudflare 임시 터널 (`cloudflared`) | Cloudflare 공식 | 계정 없이 임시 `https://….trycloudflare.com` 주소를 줘요. **껐다 켜면 주소가 바뀌어요.** | `cloudflared tunnel --url http://127.0.0.1:8767` |
| Tailscale Funnel | Tailscale 공식 (이 PC에 Tailscale이 이미 있으면 새로 설치하지 않아도 돼요) | 내 이름의 고정된 `https://이름.ts.net` 주소를 인터넷에 열어요. Tailscale 관리 화면에서 Funnel을 허용해야 해요. | `tailscale funnel 8767` |

주의: 터널이 켜져 있는 동안은 이 문이 인터넷에 보여요. 연결 번호와 OAuth를 통과하지 못하면 아무것도 할 수 없지만, 쓰지 않을 때는 터널도 끄세요.

## 5. 끄는 법 · 끊는 법

- **통째로 끄기**: '외부 연결' 화면의 스위치를 꺼요. 포트가 바로 닫혀요 (켜 둔 채 AI 스튜디오를 껐다 켜면 다시 열려요).
- **앱 하나 끊기**: '연결된 앱'에서 그 앱 옆 **[끊기]**. 그 앱의 토큰은 바로 쓸 수 없어요. **[모두 끊기]**도 있어요.
- **권한 줄이기**: '권한'에서 '읽기만'을 고르고 저장하면 이미 연결된 앱에도 바로 적용돼요.
- 공개 주소를 바꾸면 연결된 앱은 모두 끊겨요 (확인 창이 먼저 떠요).
- 급하면 터널 프로그램을 끄는 것이 가장 빨라요.

## 6. 위험과 한계

- 연결한 앱은 사장님 대신 **일을 맡기거나 결과를 읽을 수 있어요.** 결재와 완료는 항상 사장님이 해요. '일 맡기기' 단계에서는 사장님이 [실행]을 눌러야 직원이 움직이고, **'일 맡기기 + 실행 시작' 단계를 고른 프로젝트에서는 앱이 직접 실행을 시작시켜서** 구독 사용량을 써요 (자기가 맡긴 일만, 동시에 3개까지, 긴급 정지 중에는 안 돼요. 자동 실행은 기존 설정 그대로). 사용량이 걱정되는 프로젝트는 '일 맡기기'로 두세요.
- 앱이 맡긴 일을 앱이 시작시키고 결과까지 보는 것은 사장님이 보지 않는 사이에도 일어날 수 있어요. 그래도 결과를 **반영(병합)하고 끝내는 결재는 사장님만** 할 수 있어요.
- 읽기만이어도 열어 준 프로젝트의 **폴더 범위 안의, 검사를 통과한 결과 파일**(1MB 이하)은 읽을 수 있어요. 범위는 꼭 필요한 만큼만 주세요.
- **터널 주소가 바뀌면 다시 연결해야 해요** (임시 터널은 껐다 켜면 바뀌어요). 화면에서 새 주소를 저장하면 옛 연결은 끊기고, 앱 쪽도 새 주소로 다시 추가해요.
- 연결 번호가 노출돼도 5분·한 번뿐이고 사장님이 동의 화면에서 허용해야 해요. 누가 번호를 계속 틀려서 1분 잠기게 만드는 방해는 할 수 있어요.
- 앱 이름은 앱이 스스로 적은 글이라 **믿을 수 없어요.** 동의 화면과 목록에는 그대로(HTML이 아닌 글로) 보여 줘요. 내가 방금 연결하려던 앱이 맞는지 보고 허용하세요.
- ChatGPT가 쓰는 연결 주소(redirect)는 정해진 것만 등록돼요: ChatGPT 두 가지(`https://chatgpt.com/connector_platform_oauth_redirect`, `https://chatgpt.com/connector/oauth/<영문·숫자>`), Claude(`https://claude.ai/api/mcp/auth_callback`), 이 PC 안의 앱(`http://127.0.0.1:<포트>/…`, `http://localhost:<포트>/…`). OpenAI의 다른 옛 주소(`chat.openai.com`)는 `data/gateway.json`의 `extra_redirects`에 정확한 주소를 넣어야 쓸 수 있어요 (화면에는 칸이 없고, 도구 `POST /api/gateway/config`로 설정해요).
- 클라이언트 등록은 **동적 등록(DCR)만** 지원해요. 앱이 메타데이터 주소를 알려 주면 서버가 그 주소를 가져오는 방식(CIMD)은 서버가 바깥 주소를 먼저 불러야 해서 일부러 지원하지 않아요.
- 미확인: 진짜 ChatGPT·Dots와의 실제 연결, 터널(Cloudflare·Tailscale)을 거친 동작, 인터넷에서의 속도·안정성, Dots가 사용자 지정 MCP를 쓸 수 있는지. 이 작업은 모두 **하지 않았어요.**

## 7. 개발자 메모

- 코드: `studio/mcp_gateway.py` (OAuth 논리 + 서버), `studio/supervisor.py`의 `Supervisor.call_as`(확인된 신분으로 같은 권한 검사)와 `Supervisor._run`(실행 시작: `MAX_RUNNING = 3`), `studio/supervisor_mcp_http.py`의 `post(authorize=, tools=)`(기본값이면 기존 동작 그대로. 옛 감독 토큰 길은 어느 프로젝트에도 `run:true`가 없으면 `run_task`를 목록에서 숨겨요), `Gateway.tools_for`(지금 설정에서 '실행 시작'이 켜진 프로젝트가 있을 때만 `run_task`를 보여요). 기존 `/mcp`(대시보드 서버, 감독 토큰 Bearer)와 `data/supervisors.json`은 건드리지 않아요. 연결마다 `gateway-<번호>` 신분이 생기고 그 일은 `supervisor:gateway-<번호>`가 만든 것으로 기록돼요.
- 저장: `data/gateway.json`(켬·공개 주소·포트·권한[프로젝트별 `paths`·`write`·`run`]·추가 허용 주소; `write` 칸이 없는 옛 설정은 켜짐으로 읽고, 참이 아닌 값은 꺼짐으로 읽어요. **`run` 칸이 없거나 참이 아닌 값이면 꺼짐**이고, `write`가 꺼진 프로젝트에서는 켤 수 없어요 — 저장 때 `run:true & write:false`는 거절해요) · `data/gateway/clients.json` · `data/gateway/grants.json`(토큰 해시) · `data/gateway/audit.jsonl`. 인증 코드·연결 번호·동의 화면 번호표는 메모리에만 있어요.
- 대시보드 API(이 PC의 세션 토큰이 있어야 쓰기 가능, 휴대폰·같은 와이파이 쪽에는 없음): `GET /api/gateway` · `POST /api/gateway/config|permissions|code|revoke`.

- 시험: `python -m unittest tests.test_gateway` (가짜 시계, ChatGPT 흉내 클라이언트) · `node tools/dev/gateway_sim.js` · `node tools/dev/gateway_browser.cjs [--shots]`(포트 8805~8806) · 사람이 연결 전에 돌려 보는 흉내 점검 `python tools/dev/gateway_oauth_check.py`.
