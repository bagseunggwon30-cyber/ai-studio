# 해변 발표 캐릭터 — 형태를 유지한 분리 조각 움직임

2026-10-01 갱신. 사용자 피드백: 몸이 고무처럼 늘어나는 느낌을 제거한다.

## 현재 구현

평소 그림은 다리를 꼬지 않고 양발로 선 `normal-standing.png`이다. 몸통·머리·흉부·긴 머리카락·옷·왼쪽과 오른쪽의 허벅지·종아리를 실제 PNG 조각으로 나눴다. 눈과 입의 네 표정 조각을 더하고 발은 고정된 밑그림에 둔다. 총 14개 층이다.

모든 움직임은 조각 전체의 회전과 이동이다. 배율 변경, 부드러운 영역 무게, 넓은 몸 그림의 국소 밀기는 쓰지 않는다. 흉부는 독립된 조각으로 작은 수직 지연 움직임을 주며, 종아리와 허벅지는 무릎에서 연결되고 발목 회전 중심은 고정된다. 옷 뒤의 다리는 생성 편집으로 복원해 별도 옷 조각 아래에 넣었다. 머리카락은 팔과 흉부를 제외한 뒤 몸 뒤에 그린다.

이 모델은 기존 `ui/puppet.js`를 사용하는 작은 2D 조각 모델이다. Cubism `.moc3`/`.cmo3` 모델은 아니다. 작은 대기 움직임을 위한 범위이며 큰 회전이나 걷기를 위한 원화·가려진 관절의 완전한 채색은 없다. 확대하거나 큰 자세를 잡으면 조각 경계와 원화의 가장자리 흔적이 보일 수 있다. 계산상 형태를 유지하는 것과 사람이 느끼는 자연스러움은 별개이며, 최종 감각은 미리보기에서 판단해야 한다.

## 적용과 공개 파일

`data/assets/mascot/mascot.json`과 거기서 참조하는 15개 PNG를 Git 저장소에 포함한다. 나머지 실행 기록·토큰·장착 정보·원본 편집 중간 파일은 `.gitignore`로 제외한다. 그림 생성·편집 원본은 로컬 `data/assets/mascot/raw/beach-standing/generated/`에 있다.

`preview/`는 독립적인 확인 화면으로 동일한 설정과 조각을 사용한다. 이 폴더는 GitHub에서 내려받아 실제 회사·계정을 실행하지 않고 확인할 수 있다.

```powershell
python docs/design/beach-standing/preview/serve.py
```

주소는 http://127.0.0.1:8796/ 이다. 편안한 움직임, 말하기, 가볍게 기울기, 정지, 왼쪽/오른쪽 자세 확인 및 눈·입 확인 막대가 있다.

## 검증

- Godot `make_beach_rigid.gd` 실행 성공. 정지 합성에서 원화 밑그림의 불투명 부분이 빠진 픽셀 0개. 이것이 원화와 모든 픽셀의 완전한 일치를 뜻하지는 않는다.
- JS 문법 검사 및 기존 인형 엔진 점검 31개 통과.
- `node tools/dev/beach_rigid_sim.js`: 정지/좌우 자세에서 조각 모서리 길이 4,032개 사례, 무릎·발목 연결 12개 사례, 발 고정 3개 자세 통과.
- 실제 WebGL 미리보기에서 좌우 자세 확인. 이미지·스크립트 경고와 오류 없음. 최종 모델의 실제 화면을 9초 동안 211프레임 기록했다. `animation-preview.gif`와 `preview-rigid.png`는 이 화면에서 만든 자료다.
- 전체 감독 프로그램 테스트 `python -B -m unittest discover -s tests -t .`: 217개 통과.
- 실제 회사 서버·AI 직원·휴대폰 동작: 실행 안 함.

## 도구

`tools/sprites/make_beach_rigid.gd`가 머리카락·옷에 가려진 밑그림과 원화에서 조각을 잘라낸다. 좌표는 현재 1021×1540 원화에 맞췄으므로 다른 그림에 그대로 적용하면 안 된다. `tools/sprites/make_beach_mascot.gd`는 기존 눈·입 조각 정리를 담당한다. 공개 저장소에는 완성된 조각을 포함하므로 원본 생성 서비스 없이 실행할 수 있다.
