# 진행판 발표 캐릭터 바꾸기

진행판(칸반 화면) 오른쪽에서 보드판을 들고 진행 상황을 알려 주는 캐릭터는 **그림 파일만 바꿔 끼우면** 바뀝니다. 코드는 고치지 않습니다.

- 기본 그림: `ui/assets/mascot/` — Codex로 그린 일러스트 '하나'. 기상 캐스터처럼 오른쪽에 서서 왼쪽 위의 돌리는 판을 손바닥으로 가리킵니다. 프로그램을 새로 받으면 덮어써지니 여기는 고치지 않습니다.
- 사장님 그림: **`data/assets/mascot/`** 폴더를 만들고 `mascot.json`과 PNG 그림을 넣습니다. 이 폴더가 있으면 그것을 먼저 씁니다.
- 반영: 화면을 새로고침(F5)하면 바로 바뀝니다. 서버를 다시 켤 필요는 없습니다.
- 되돌리기: `data/assets/mascot/` 폴더를 지우면 기본 그림으로 돌아옵니다.

## 그림

- PNG. 배경은 투명이 좋습니다 (진행판 오른쪽 칸의 밝은 색 위에 올라갑니다).
- 표정 3장: **평소**(꼭 있어야 함), **기쁨**(결재 올림·완료 때), **걱정**(막힌 일이 있을 때). 기쁨·걱정이 없으면 평소 그림을 씁니다.
- 판은 프로그램이 그립니다. 두 가지 방법이 있습니다.
  - **판 옆에 서서 가리키는 그림** (기본 그림 방식): 판 자리를 비워 두고 `board`에 판 자리를 적습니다. `stand`로 받침(`"pole"` 가운데 기둥, `"easel"` 이젤 다리), `behind: true`면 캐릭터가 판 앞에 섭니다 (머리카락·손이 판 위로).
  - **판을 손에 든 그림**: 판의 흰 종이 칸을 비워 두고 그 자리를 `board`에 적습니다. `frame: false`면 테두리 없이 종이만 겹쳐 그립니다.
- 파일 이름은 영어·숫자·`_` `-` `.` `@`만, `.png`로 끝나야 합니다 (예: `me-normal.png`). 다른 폴더의 그림은 쓸 수 없습니다.

## mascot.json

```json
{
  "version": 1,
  "name": "하늘",
  "box": { "w": 396, "h": 560 },
  "board": { "x": 2, "y": 6, "w": 222, "h": 238, "stand": "pole", "behind": true },
  "moods": {
    "normal":  { "image": "me-normal.png",  "x": 78, "y": 80, "h": 480 },
    "happy":   { "image": "me-happy.png",   "x": 78, "y": 80, "h": 480 },
    "worried": { "image": "me-worried.png", "x": 78, "y": 80, "h": 480 }
  }
}
```

| 칸 | 뜻 |
|---|---|
| `version` | 항상 `1` |
| `name` | 진행판 위에 보이는 이름 (12자까지) |
| `box` | 캐릭터를 놓는 상자 크기(점 단위). 화면에서는 넓이 396에 맞춰 늘리거나 줄입니다 |
| `board` | 보드판 위치·크기 (상자 왼쪽 위가 0,0). 상자 밖으로는 나가지 않게 잘립니다. 판 글자 크기는 판 크기에 맞춰 바뀝니다 |
| `board.stand` | 판 밑 받침: `"pole"` 가운데 기둥(상자 바닥까지), `"easel"`(또는 `true`) 이젤 다리, 없으면 받침 없음 |
| `board.behind` | `true`면 판이 캐릭터 **뒤**에 (캐릭터가 판 앞에 서서 가리킬 때). 없으면 판이 캐릭터 앞 |
| `board.frame` | `false`면 테두리 없이 종이만 (손에 든 판의 흰 종이 자리에 겹칠 때) |
| `moods.*.board` | 표정 그림마다 판 자리가 조금 다를 때만 (없으면 위의 `board`) |
| `moods.*.x`, `y` | 그 표정 그림의 왼쪽 위 자리 (상자 기준) |
| `moods.*.h` | 그 표정 그림의 높이. 넓이는 그림 비율대로 |

## 움직임 (있어도 되고 없어도 됨)

캐릭터는 효과 스위치(상단 바의 별)가 켜져 있으면 저절로 움직입니다: 숨쉬기(아주 조금 커졌다 작아지며 기울기), 기쁠 때 폴짝, 걱정할 때 흔들림, 판이 돌 때 판 쪽으로 기울기. 그림이 더 있으면 아래도 합니다.

```json
"anim": {
  "blink": { "image": "me-blink.png", "x": 258, "y": 149.6, "h": 24 },
  "point": { "image": "me-point.png", "x": 78, "y": 80, "h": 480 }
}
```

| 칸 | 뜻 |
|---|---|
| `anim.blink` | 눈 깜빡임: **평소 그림 위에 잠깐(0.13초) 겹치는 눈 감은 조각**. 조각 그림과 그 자리(상자 기준 `x`·`y`, 높이 `h`). 2.6~6초마다, 가끔 두 번. 평소 얼굴일 때만 |
| `anim.point` | 판이 돌 때 1.3초 바꾸는 손짓 전신 그림 (표정 그림과 같은 자리 규칙). 평소 얼굴일 때만 |
| `anim.blink.eyesOnly` | 전신 눈 감은 그림을 `anim.blink`에 쓸 때 `true`: 눈 주변만 부드럽게 겹쳐 그림 전체가 깜빡이지 않게 함 |
| `anim.chest` | 평소 전신 그림을 같은 자리·크기로 한 번 더 지정하면 흉부 주변만 작게 흔들림. 효과 스위치가 켜졌을 때만 작동 (아래 '뼈대' 모드에서는 쓰지 않음) |

기본 그림은 `tools/sprites/draw_mascot.py blink point`로 Codex가 평소 그림을 고쳐 그리고, `make_mascot.gd`가 평소 그림과 **달라진 곳 중 가장 큰 덩어리(눈)**만 잘라 `blink.png`로 만듭니다 (Codex가 머리카락 몇 가닥을 조금씩 다시 그려도 그 부분은 쓰지 않음).

설정이 규격에 맞지 않으면(판 번호가 1이 아님, 파일 이름이 이상함, 평소 그림이 없음, 숫자가 아님 등) 기본 그림을 쓰고 캐릭터 밑에 "캐릭터 설정 파일이 규격에 맞지 않아 기본 그림을 썼어요"가 뜹니다.

## 뼈대(rig) — 라이브2D처럼 움직이기

`mascot.json`에 **`rig`** 칸을 더하면, 그림 한 장을 촘촘한 그물(mesh)로 나눠 WebGL로 휘어서 움직입니다 (`ui/puppet.js`). 진짜 라이브2D는 유료 프로그램과 부위별 그림이 있어야 해서, 그림 한 장(+눈 깜빡임 조각)만으로 되는 작은 엔진을 직접 만들었습니다. **뼈대가 없거나 틀리거나 WebGL을 못 쓰면 위의 '움직임'(CSS) 방식으로 움직입니다.** 틀린 뼈대는 캐릭터 밑에 "캐릭터 뼈대 설정이 규격에 맞지 않아 예전 움직임을 썼어요"가 뜹니다.

- 뼈대 모드에서는 `anim.chest`(흉부 조각)를 **쓰지 않습니다**. 흉부만 움직이는 부위·휘기·물리도 만들지 않습니다. 숨쉬기는 몸 윗부분 전체가 1px 오르내리는 정도입니다.
- 그림 세 장(평소·기쁨·걱정)과 손짓 그림은 **같은 크기·같은 자리**여야 합니다 (같은 그물에 그리고 표정이 바뀔 때 0.25초 겹쳐 바뀝니다). 크기가 다르면 화면 콘솔에 경고만 뜹니다.
- 움직임(가만히 있기·숨쉬기·깜빡임·바라보기·폴짝·흔들림·손짓·말하기)은 엔진이 스스로 정합니다. 뼈대에는 '어느 부분이 어떻게 휘는지'만 적습니다.

```json
"rig": {
  "version": 1,
  "size": { "w": 530, "h": 800 },
  "grid": { "cols": 28, "rows": 42 },
  "regions": {
    "head":  { "poly": [[205,50],[335,-10],[412,65],[410,190],[392,238],[262,240],[212,268],[196,110]], "feather": 20 },
    "hairR": { "poly": [[335,80],[400,95],[480,260],[515,430],[445,455],[447,300],[350,160]], "feather": 20 }
  },
  "deformers": [
    { "type": "rotate", "region": "hairR", "pivot": [360,150], "param": "hairSway", "k": 5, "falloff": { "from": [360,150], "to": [470,440], "power": 1.5 } },
    { "type": "shift",  "region": "head", "param": "angleX", "kx": 5 },
    { "type": "rotate", "region": "head", "pivot": [290,238], "param": "angleZ", "k": 8 },
    { "type": "shift",  "region": "*", "param": "posY", "ky": -27 }
  ],
  "physics": [
    { "out": "hairSway", "in": [["angleZ", 0.6, -0.05], ["bodyZ", 0.8]], "stiffness": 20, "damping": 3.5 }
  ],
  "layers": [
    { "id": "base" },
    { "id": "blink", "image": "blink.png", "x": 300, "y": 116, "h": 40, "show": { "param": "eyeOpen", "max": 0.35 }, "moods": ["normal"] }
  ]
}
```

| 칸 | 뜻 |
|---|---|
| `size` | 뼈대 좌표의 크기 = **평소 그림의 픽셀 크기** (기본 하나 530×800, 사장님 그림 1021×1540). 그림 크기와 다르면 경고 |
| `grid` | 그물 칸 수 (가로·세로, 4~64). 촘촘할수록 부드럽지만 계산이 늘어납니다 |
| `regions` | 영역 이름 → 모양. `ellipse` `[가운데x, 가운데y, 가로반지름, 세로반지름]` 또는 `poly` `[[x,y], …]`(점 3~64개). `feather` = 경계 **바깥**으로 무게가 0까지 부드럽게 줄어드는 폭. 안쪽은 무게 1. 영역 이름은 영어·숫자·`_`, 영어로 시작, 24자까지, 32개까지. `"*"`는 어디나 무게 1 (영역을 따로 안 적음) |
| `deformers` | 휘는 방법 (적힌 순서대로, 나중 것은 이미 휜 자리에 적용). `type`: `rotate`(pivot 둘레로 `k`도, 시계 방향이 +) · `shift`(`kx`, `ky` 픽셀) · `scale`(pivot 기준 `1+kx·값`, `1+ky·값`). `region`: 영향받는 영역. `param`: 움직이는 매개변수. `k`·`kx`·`ky`는 매개변수 값이 **1일 때의 최대치**. 최대 64개 |
| `deformers[].falloff` | `{ "from": [x,y], "to": [x,y], "power": 1.5 }` — from→to 방향으로 갈수록 무게가 커집니다 (머리카락 끝이 더 흔들리게) |
| `deformers[].layers` | (선택) `["hairR"]`처럼 층 id를 적으면 **그 층에만** 적용하고 base를 비롯한 나머지 층은 건너뜁니다. 없으면 모든 층. 없는 층 id를 적으면 뼈대 전체가 틀린 것으로 봅니다 |
| `physics` | 스프링 물리 (최대 16개). `out`은 아무 이름(`hairSway`·`skirtSway` …, 표준 매개변수 이름은 안 됨) — 이 이름을 deformer의 `param`으로 씁니다. `in`은 `[매개변수, 가중치]`(선택으로 셋째 숫자 = 입력이 움직이는 속도를 목표에 더하는 정도, 음수면 반대로 쏠림). `stiffness`(기본 20)·`damping`(기본 3.5) |
| `layers` | 그리는 순서. `{"id":"base"}` = 지금 표정 그림. 다른 층은 `image`(같은 폴더의 png)·`x`·`y`·`h`(뼈대 좌표, 넓이는 그림 비율)·`show`({`param`,`min`,`max`,`fade`}: 그 범위에서 보임)·`mask`(영역 이름: 그 무게만큼만 보임 — 전신 눈 감은 그림을 눈 주변만 겹칠 때)·`moods`(보일 표정, 없으면 모두)·`under: true`(base 밑에). **모든 층이 같은 그물 변형을 받아** 머리와 함께 움직입니다. `layers`를 아예 안 적으면 base + (`anim.blink`가 있으면) blink 층을 자동으로 만듭니다 |
| `bases` | (선택) `{ "normal": "normal-nohair.png", "happy": "…", "worried": "…", "point": "…" }` — 뼈대 모드에서 base 층이 표정 그림 대신 이 그림을 씁니다 (없는 표정은 원래 `moods` 그림). 크기는 `size`와 같아야 합니다. `point` 그림은 손짓 deformer(param `point`)가 없을 때만 씁니다. 예전 CSS 방식은 `moods` 그림을 그대로 씁니다 |

**매개변수** — 값의 범위는 -1..1 (`breath`·`eyeOpen`·`mouthOpen`·`point`는 0..1). 엔진이 움직이는 표준 이름: `angleX`(좌우 돌리기) `angleY`(끄덕, +가 고개 듦) `angleZ`(갸웃) `bodyX` `bodyZ` `breath`(숨) `eyeOpen`(눈 뜸 정도) `eyeX` `eyeY` `mouthOpen`(말할 때 입: 0 = 말하지 않을 때, 말하는 동안 0.12 다문 입 ~ 1 벌림을 음절처럼 오감) `point`(손짓) `posY`(위로 뜸, +가 위) `squash`(폴짝 착지 때 눌림). 물리 `out` 이름은 자유입니다.

**좌표계** — 모든 좌표는 평소 그림의 **픽셀 좌표**입니다 (왼쪽 위가 0,0, 아래·오른쪽이 +). 상자 좌표(`box`, `moods`의 `x`·`y`·`h`)와는 `moods.normal`의 자리·높이로 바뀝니다: `뼈대 좌표 × (h ÷ size.h) + (x, y)`. 영역의 무게는 그림이 **쉬는 자리**에서 한 번만 계산합니다.

**늘어나 보이지 않게 (기본 원칙)**
- 부위(머리·아래팔·머리카락·치마)는 안쪽 무게 1인 **단단한 조각**으로 `rotate`/`shift`만 하고, `feather`는 **관절 근처 좁은 띠**(530 좌표 기준 15~25px: 턱 밑 목, 머리카락 뿌리, 팔꿈치, 허리)에만 둡니다.
- `scale`은 쓰지 않습니다 (숨쉬기는 몸 윗부분을 1px 오르내리는 `shift`, 폴짝은 몸 전체 `shift`). 얼굴 안쪽만 따로 밀지도 않습니다 — 평면 그림이라 이목구비가 찌그러집니다. 머리 돌리기(`angleX`)는 머리 조각 전체를 2~3px 미는 것으로.
- 가만히 있을 때 움직임은 작게: 머리 갸웃 ±2°, 머리 이동 ±2px, 몸 기울기 ±0.5°, 머리카락 끝 ±2~3°, 치마 밑단 ±1.5° (5~8초 주기, 가끔 완전히 쉬는 순간이 있습니다). 그림 한 장에서 부위를 못 떼는 그림은 이보다 더 작게.
- 부위별 그림(머리카락 층 등)이 있으면 늘리지 않고 그 층을 통째로 움직입니다 (기본 하나가 그렇게 움직입니다, 아래).

**맞추는 법** — 서버(연습용 회사 권장)를 켜고 주소 뒤에 붙여서 봅니다. 서버에 아무것도 보내지 않는 개발용 주소입니다.
- `#view=board&demo=rig` — 가운데 칸에 큰 인형과 **매개변수 슬라이더**가 뜹니다. '영역 색 보기'를 켜면 영역마다 다른 색으로 무게가 겹쳐 보여서, 영역이 그 부위를 덮는지 확인할 수 있습니다. '그물 선 보기'는 휜 그물을 보여 줍니다. `&overlay=regions,mesh`로 처음부터 켤 수 있습니다.
- `#view=board&pose=angleZ:1,hairSway:-1` — 그 값으로 멈춘 자세 (물리 `out`도 적을 수 있고, 안 적으면 입력이 그대로일 때의 값). `mood:happy`(또는 `worried`, `normal`)를 함께 적으면 그 표정으로 멈춥니다. `demo=rig`와 같이 쓰면 그 자세로 시작합니다.
- `tools/dev/capture.ps1`의 `rig`·`rigreg`·`rigpose`가 위 주소를 캡처합니다.
- 각 매개변수를 ±1로 밀어 보며 ① 영역이 그 부위를 덮는지 ② 경계가 찢어지거나 두 겹으로 보이지 않는지 ③ 머리를 갸웃할 때 목이 자연스러운지 확인하고 숫자를 고칩니다. 효과 스위치를 끄면(또는 진행판을 떠나면) 그리기가 멈춥니다.

**기본 하나는 부위 층으로 움직입니다** (2단계의 첫 걸음). `ui/assets/mascot/`의 파일과 쓰임:

| 파일 | 쓰임 |
|---|---|
| `normal-nohair.png` `happy-nohair.png` `worried-nohair.png` `point-nohair.png` | 긴 머리카락을 지우고 그 밑을 채운 몸 그림. 뼈대의 `bases`로 base 층이 표정 그림 대신 씁니다 |
| `hair.png` (530×800) | 긴 머리카락만. 층 `hairR`(base 위). `hairSway`는 `"layers": ["hairR"]`로 이 층에만 걸립니다. 머리·몸의 휘기는 이 층에도 그대로 걸려 머리와 함께 움직입니다 |
| `eyes-half.png` · `blink.png` (x300, y116) | 눈. `eyeOpen` 1 = 원래 그림(윙크 얼굴), 0.35~0.75 = 반쯤 감은 눈, 0.35 미만 = 감은 눈 (깜빡일 때 반쯤을 거쳐 감김). 평소 얼굴일 때만 |
| `mouth-closed.png` (x274, y172) · `mouth-half.png` (x274, y174) | 입. **가만히 있을 때는 조각 없이 원래 그림의 벌린 웃음 그대로.** 말할 때(`mouthOpen` 0.04~0.42 다문 입, 0.3~0.8 반쯤, 그 밖은 원래 그림)만 음절처럼 바뀝니다. 평소 얼굴일 때만 |

- 예전 `normal.png` 같은 표정 그림은 그대로 둡니다 (뼈대가 없거나 WebGL을 못 쓸 때의 CSS 방식용).
- `hair.png`는 위쪽이 y≈85에서 들쭉날쭉 잘려 있고 머리카락 뿌리는 몸 그림에 있으므로, 뿌리 둘레를 축으로 위쪽은 거의 안 움직이게(`falloff`) 했습니다. 팔꿈치 옆(원래 팔 뒤에 있던 머리)과 소매 둘레는 영역 `hairR`의 무게를 0으로 낮춰 팔 윤곽이 따라 나오지 않게 했습니다. 테두리에 옷·살 색 반투명 픽셀이 있어서, 이 무게를 없애면 팔 옆에 옅은 띠가 따라 움직입니다.
- 만드는 법: `python tools/sprites/draw_mascot.py nohair mouth-closed mouth-half eyes-half` (Codex가 그림, 구독 사용량이 듭니다) → `godot --headless --path tools/sprites --script res://make_mascot_parts.gd -- --root=<프로젝트 폴더>` (평소 그림과 달라진 곳만 잘라 `assets-raw/mascot/parts/`에 `hair.png`·`*-nohair.png`·조각과 `parts.json`(자리·확인 수치)을 씁니다) → 그 폴더의 `hair.png`, `*-nohair.png`, `mouth-closed.png`, `mouth-half.png`, `eyes-half.png`를 `ui/assets/mascot/`에 복사 (`blink.png`·`check-*.png`는 복사하지 않음).
- 부위 그림이 없는 그림은 층 없이 뼈대의 휘기만 씁니다 (위 '늘어나 보이지 않게'). 사장님 그림은 지금 이 방식입니다 — 부위 층을 더하는 법은 바로 아래.

### 내 그림도 부위 층으로 (GPT로 한 곳씩 고친 그림 4장)

기본 하나처럼 긴 머리카락·입·눈을 층으로 움직이게 하려면, **원본 그림을 한 곳만 고친 그림 4장**이 필요합니다. GPT 그림 편집에 시킵니다. 프로그램이 원본과 비교해 달라진 곳만 잘라 층으로 만듭니다 (몸 그림은 원본 그대로이고, 새로 그리는 것은 지운 머리카락 밑·입·눈뿐입니다).

**지킬 것**
- 매번 **원본(`data/assets/mascot/normal.png`)을 새로 첨부**해서 **한 장씩** 만듭니다. 고친 그림을 또 고치면 조금씩 틀어집니다.
- 크기나 위치가 원본과 다르게 나오면 "그림 크기와 위치를 원본과 똑같이 다시"라고 한 번 더 말합니다. 몇 픽셀 밀린 것은 프로그램이 맞춥니다.
- 배경은 투명이 제일 좋고, 초록(#00FF00)이나 흰색 같은 단색도 됩니다 (프로그램이 지웁니다).
- 파일 이름을 아래대로 저장해 **`data/assets/mascot/raw/`** 에 넣습니다 (이 폴더는 화면에 내보내지 않는 원본 자리).

**모든 명령 앞에 붙일 말**
```text
첨부한 그림을 편집해 줘. 아래 '바꿀 것' 말고는 모든 픽셀을 그대로 둬: 같은 인물, 얼굴, 머리 모양, 옷, 자세, 그림 크기와 위치(여백 포함), 그림체와 색. 그림 크기는 원본과 똑같이, 배경은 원본처럼 투명하게.
```

| 저장할 이름 | 바꿀 것 (앞의 말 뒤에 이어서) |
|---|---|
| `nohair.png` | 그림 오른쪽으로 길게 흘러내린 긴 머리카락(어깨 아래로 내려오는 부분)만 지워 줘. 머리카락이 가리던 곳이 배경이면 투명하게, 몸·팔·옷을 가리던 곳이면 원래 있던 것처럼 자연스럽게 이어서 그려 줘. 머리 위쪽 머리카락, 앞머리, 얼굴 옆 머리, 꽃 장식, 선글라스는 그대로. |
| `mouth-closed.png` | 입만 입술을 다문 부드러운 미소로 바꿔 줘 (이가 보이지 않게). 눈과 얼굴의 다른 곳은 그대로. |
| `mouth-half.png` | 입만 지금보다 절반쯤 덜 벌린 미소로 바꿔 줘 (말하는 중간처럼). 눈과 얼굴의 다른 곳은 그대로. |
| `eyes-half.png` | 두 눈만 편안하게 반쯤 감은 모습으로 바꿔 줘 (윗눈꺼풀이 눈동자 절반쯤을 덮게). 눈썹, 입, 얼굴의 다른 곳은 그대로. |

감은 눈은 이미 있는 `blink.png`(전신)를 그대로 씁니다. 원본에 윙크처럼 한쪽 눈이 이미 감겨 있으면 `eyes-half` 문장을 "뜬 눈만"으로 바꿉니다.

**그다음 (Claude가 함)**
1. 도구를 돌려 층 그림을 만든다: `godot --headless --path tools/sprites --script res://make_mascot_parts.gd -- --prepared --source=data/assets/mascot/raw --normal=data/assets/mascot/normal.png --out=<작업 폴더>`. 고친 그림마다 배경(투명·초록·단색)을 지우고, 원본 자리에 자동으로 맞춘 뒤(가로세로 크기·이동 탐색), 달라진 곳만 잘라 `hair.png`(긴 머리카락 층, 원본과 같은 크기), `normal-nohair.png`(머리카락 밑을 채운 몸), `mouth-closed.png`·`mouth-half.png`·`eyes-half.png`(작은 조각), `parts.json`(자리·맞춘 값·확인 수치)과 확인 그림 `check-*.png`를 씁니다. 원본과 너무 달라 맞추지 못하면 그 그림만 거절하고 어느 것을 다시 만들지 알려 줍니다. 눈·입 조각이 엉뚱한 곳(옆머리·옷 무늬의 잔번짐)을 자르면 `--eyes=x,y,w,h`·`--mouth=x,y,w,h`(원본 그림 좌표)로 눈·입이 있는 곳을 알려 줍니다. 픽셀 기준값(칸 크기·번짐 폭)은 그림 높이/800에 비례해 늘립니다. (시험: 기본 하나 조각으로 만든 가짜 GPT 그림 — 완벽한 그림·크기 2%/위치 12px 틀어진 흰 배경 그림·2배 그림 — 세 가지 모두 같은 조각 자리로 나오고 기본 하나 결과는 바이트까지 그대로.)
2. 확인 그림을 눈으로 보고, 층 그림을 `data/assets/mascot/`에 복사하고 `mascot.json`의 `rig`에 `bases`·층(`hairR`, `eyesHalf`, `mouthClosed`, `mouthHalf`)과 `hairSway`의 `"layers": ["hairR"]`를 더합니다 (기본 하나의 `rig`가 본보기). 표정이 평소 하나뿐이라 `bases`는 `normal`·`happy`·`worried`를 모두 `normal-nohair.png`로 적습니다.
3. 연습용 회사에서 `#view=board&demo=rig`로 팔·머리 이음새와 입·눈 단계를 확인한 뒤 알려 드립니다.

## 판에 나오는 것 (프로그램이 씀)

- 앞면: 아직 안 끝난 가장 최근 지시의 진행 — "이번 지시 · 제목 · N% · M개 중 K개 완료", 막힌 일·결재 기다리는 일 수. 지시에서 나오지 않은 일은 '따로 맡긴 일'로 셉니다. 숫자는 모두 실제 작업 상태로 셉니다.
- 뒷면: 작업이 다음 단계로 넘어가면 판이 한 바퀴 반 빙글 돌아 "작업 번호 · 담당 · 제목 · 전 단계 → 새 단계"와 단계 점(대기·작업·검사·결재·완료)을 4초쯤 보여 주고 다시 돌아옵니다. 여러 개가 한꺼번에 바뀌면 차례로 (최대 6개).
- 효과 스위치(상단 바의 별)가 꺼져 있으면 뒤집는 움직임 없이 바로 바뀝니다.
