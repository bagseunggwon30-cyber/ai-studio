# AI 스튜디오 화면 설계 기준

게임처럼 보이는 AI 회사 화면의 기준 이미지입니다. 구현할 때 이 이미지들의 분위기, 배치, 캐릭터를 따릅니다.
이미지를 만든 프롬프트 원문은 [prompts.md](prompts.md)에 있습니다.
구현용 화면 설계서는 [SPEC.md](SPEC.md), 실제 화면에 쓸 에셋(배경·캐릭터·소품) 프롬프트는 [asset-prompts.md](asset-prompts.md)에 있습니다.

## 스타일 규칙

- 16비트 픽셀 아트, 3/4 탑다운 시점. 따뜻한 나무 바닥, 크림색 벽, 창밖 낮 하늘.
- 상단 바(짙은 자주 `#2E2B3D`)와 하단 명령창은 **모든 화면에 고정**.
- 강조색 라벤더 `#7F77DD`. 상태색: 청록 = 완료, 호박 = 진행 중, 산호 = 확인 필요, 빨강 = 정지.
- 정보는 표 대신 캐릭터, 말풍선, 물건으로 보여 준다. 글자는 짧게.
- 팝업은 사무실을 어둡게 깔고 가운데에 종이나 카드로 띄운다.
- 이미지 속 글자는 참고용이다. 구현할 때 글자는 HTML로 넣는다 (한글 픽셀 폰트).

## 그림 요소와 실제 기능

| 그림 | 실제 기능 |
|---|---|
| 편지함 숫자 | 결재 대기 수. 누르면 결재함 |
| 에너지 바 | 오늘 남은 실행 여유 (하루 실행 상한 − 오늘 실행 수) |
| 휴식터 | 할 일이 없는 직원이 쉬는 곳. 일을 받으면 책상으로 돌아간다 |
| 빨간 버튼 | 긴급 정지. 불이 꺼지고 모두 멈춘다 |
| 시계·일차 | 회사 설립 후 날짜와 현재 시각 |
| 퀘스트 보드 | 작업 목록 (대기 → 진행 중 → 결재 대기 → 완료) |
| 말풍선 | 직원이 지금 하는 일 (실시간) |
| 합격 도장 | 품질 검사(신뢰 테스트) 통과 |
| 회의실 | 기획 회의. 지시를 작업 카드로 나누고 CEO가 고른다 |
| 완성작 선반 | 끝낸 게임과 보고서. 누르면 실행하거나 연다 |
| 레벨·능력치 | 실제 기록. 정확도 = 첫 시도 통과율, 속도 = 평균 작업 시간 |
| 스킬 학습 게시판 | 직원에게 새 규칙·도구를 가르치는 곳. 빈 칸은 나중에 뽑을 직원 자리 |
| 책 버튼 | 업무 일지 |

## 고칠 점과 정할 것

- 결재 창 이미지는 상단 바가 비어 있고, 완성작 진열장 이미지는 상단 바와 하단 명령창이 모두 없다. 구현할 때는 다른 화면처럼 둘 다 유지한다.
- '스킬 학습' 게시판과 '휴식터'는 이미지 생성 중에 AI가 추가했다. 휴식터는 일 없는 직원이 쉬는 곳으로 확정. 스킬 학습 게시판은 Claude 스킬 방식으로 직원에게 지침을 가르치는 곳으로 확정 (2026-09-28, SPEC 'CEO 결정 반영 메모').
- 에너지 0 전용 화면은 만들지 않는다 (CEO 결정).
- AI가 장식 문구를 몇 개 더 넣었다 ("좋은 게임을 만들어요!" 포스터, 일지 옆 메모 등). 구현 때 빼거나 CEO가 정한 문구로 바꾼다.
- 편지함 숫자가 화면마다 2 또는 3으로 다르다. 목업의 예시 값일 뿐이고 실제로는 결재 대기 수가 들어간다.
