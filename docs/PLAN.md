# AI Studio 계획 (정본)

기준일 2026-09-28. 이 문서가 계획의 정본입니다. 다운로드 폴더의 GPT 기획서(`EXECUTION_PLAN.md`, `PLAN_NO_API.md`,
`START_HERE*.md`)는 참고 자료이며, 특히 `START_HERE.md`와 `EXECUTION_PLAN.md`의 API 작업자·API 요금 부분은 **폐기**입니다.

## 확정 조건

- API 키 사용 안 함. 본인 구독으로 로그인한 공식 CLI만 (Codex: ChatGPT 로그인, Claude Code: claude.ai 로그인)
- 1인 운영, Windows 11 로컬 PC, 파이썬 표준 라이브러리
- 첫 제품: Core Courier (Godot 4.7.2, 90초 코어 회수 2D 게임) + 리서치 보고서 1건
- 완료 판정: 신뢰 테스트 + 정확한 후보 커밋 + CEO 결재. 재미·아트는 사람이 판단

## Core Courier 제작 순서

1. **T0001** RunState 핵심 규칙 (신뢰 테스트 8개) — 첫 작업으로 등록됨
2. 플레이어 이동·방·코어·출구 씬 (메인 씬 지정)
3. 적 순찰과 피격
4. HUD, 결과 화면, 일시정지·재시작
5. Windows 내보내기와 실제 화면 스크린샷 → 사람 플레이 검수

2~5는 본사에서 지시하면 기획 담당이 작업 카드로 나눕니다. 화면이 있는 작업은 자동 테스트가 없으므로
(아직 신뢰 테스트는 규칙 로직만 검사) 리뷰와 CEO 확인의 비중이 커집니다. 씬 검증(헤드리스 로드, 스크린샷)은
5단계 전에 `trusted/`에 추가합니다 — CEO 또는 Claude가 작성하고, 작업자(Codex)는 수정하지 않습니다.
