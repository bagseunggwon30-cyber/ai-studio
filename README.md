# AI Studio

1인 AI 게임 스튜디오. CEO(사람)가 지시하고 결재하며, AI 직원(Codex·Claude Code)이 기획·개발·리뷰·리서치를 합니다.
회사 규칙과 기록은 모두 이 폴더의 파일이고, 감독 프로그램(`studio.py`)이 그 파일대로 일을 돌립니다.

- API 키를 쓰지 않습니다. 본인 구독으로 로그인한 공식 CLI(Codex, Claude Code)만 씁니다.
- '완료'는 에이전트의 말이 아니라 신뢰 테스트, 후보 커밋, CEO 결재로 정해집니다.
- 파이썬 표준 라이브러리만 씁니다. 설치할 패키지가 없습니다.

## 시작

```powershell
git clone https://github.com/bagseunggwon30-cyber/ai-studio.git
cd ai-studio
python studio.py doctor     # 도구·로그인 점검
python studio.py serve      # 대시보드 열기 → http://127.0.0.1:8765
```

Python 3.11 이상과 Git이 필요합니다. AI 직원은 본인이 로그인한 Codex·Claude Code CLI를 사용합니다. `studio.toml`의 Godot 경로는 본인 PC에 맞춰 설정합니다.

개발할 제품 폴더는 `projects/` 아래에 따로 준비하고 `trusted/projects/` 설정과 연결합니다. 제품 저장소는 이 감독 프로그램과 별도 Git 저장소입니다. 폴더가 준비되면 `python studio.py init`으로 Git 초기화와 첫 작업을 준비합니다. 이 명령은 없는 제품 폴더를 자동으로 만들어 주지는 않습니다.

2026-10-01 공개본에는 분리 조각 방식으로 수정한 해변 발표 캐릭터를 포함했습니다. [캐릭터 구현과 독립 미리보기](docs/design/beach-standing/README.md)를 참고하세요. 로그인 토큰과 실제 작업 기록은 저장소에 포함하지 않습니다.

## 화면

게임형 화면으로 바꾸는 중입니다. 설계는 [docs/design/](docs/design/README.md), 진행 상황은 [SPEC.md](docs/design/SPEC.md)의 '진행 상황'에 있습니다. 다른 세션에서 이어서 작업할 때는 [docs/HANDOFF.md](docs/HANDOFF.md)부터 읽으세요.

- **2026-09-30부터 화면은 진행판(칸반 보드) 하나만 씁니다.** 사무실(도트 본사) 화면은 꺼 두었습니다 (코드와 그림은 남아 있고, 주소 끝에 `#view=office`를 붙이면 개발용으로 켤 수 있습니다). 아래 설명 가운데 '본사'·'책상'·'흰 판'은 그 사무실 화면 이야기이고, 같은 기능(결재함·스킬 학습·직원·MCP 보관소 등)은 진행판 왼쪽 메뉴에서 엽니다. 자세한 것은 [docs/HANDOFF.md](docs/HANDOFF.md) 0-4f.
- 지금 `ui/`는 4단계까지 됐습니다. 게임 화면이 감독 프로그램과 연결돼, 명령창 지시 → 회의실 기획안 승인 → 퀘스트 실행 → 결재 도장 → 완성작까지 실제 작업으로 움직입니다. 직원은 실제로 일하는 역할에 따라 책상·휴식터를 오가고, 긴급 정지 버튼은 회사를 멈춥니다.
- 직원 상태창의 "꾸미기"에서 의상(기본·여름 옷), 머리색, 옷 색, 키, 체격을 바꿀 수 있습니다. 이름·한마디·스킬은 `studio.toml`의 역할마다 적습니다.
- 본사의 흰 판(스킬 학습)에서 직원에게 스킬을 가르칩니다. Claude 스킬과 같은 모양(`skills/<이름>/SKILL.md`)으로 저장되고, 배운 직원은 다음 작업부터 그 지침을 따릅니다. 직접 가르치거나, 직원에게 공부를 맡기고 정리해 온 것을 승인합니다. 한 번에 안 풀린 일은 끝난 뒤 직원이 스스로 돌아보고 스킬을 새로 만들거나 고쳐 옵니다 (고치면 판이 오르고 옛 판은 `history/`에 남음, 배우는 것은 승인 뒤, 게시판 스위치로 끌 수 있음).
- 직원 상태창의 AI 단추로 직원마다 끼울 AI(Codex·Claude 모델, 생각 깊이)를 바꿉니다. 파일을 고치는 일(개발·리서치)에는 Codex만 끼울 수 있습니다.
- 꾸미기의 "새 옷 만들기"(의상 제조실)와 직원 목록의 "새 직원 만들기"(캐릭터 제조실, 최대 3명)는 Codex 그림 생성으로 그림 3장을 그려 결재에 올립니다. 승인하면 옷이 생기거나 새 직원이 회사에 들어옵니다.
- 효과음은 처음에 꺼져 있습니다. 상단 바 스피커 버튼으로 켭니다. 글꼴은 한글 도트 글꼴 Galmuri11(SIL OFL)입니다.
- `serve --fake`(가짜 실행기)는 개발 확인용입니다. 결재하면 가짜 변경이 제품 저장소에 병합되므로 회사 폴더의 사본에서만 쓰세요. F2는 개발용 패널입니다.
- 예전 관리용 대시보드는 로컬 `ui-old/`에 보관돼 있고, 공개 저장소에는 포함하지 않습니다.

```
  studio.toml            회사 설정: 직원 모델·권한, 한도, 도구 경로
  ui/                    게임형 화면 (index.html, app.js, scene.js, popups.js, data.js, assets/)
  assets-raw/            에셋 원본 (배경, 캐릭터 시트)
  tools/sprites/         캐릭터 시트 → 동작별 띠로 자르는 Godot 도구
  company/               회사 운영 체계 — 규칙, 역할, 결정 기록, 첫 작업
  trusted/               신뢰 영역 — 프로젝트별 검증 명령과 수용 테스트 (작업자 수정 불가)
  projects/              제품 저장소들 (각각 별도 git 저장소)
    core-courier/        첫 게임 (Godot 4.7)
    studio-docs/         리서치 보고서·문서
  data/                  작업 카드, 활동·실행 기록, 검증 증거 (자동 생성)
  worktrees/             작업별 격리 폴더 (자동 생성·정리)
  docs/PLAN.md           전체 계획과 진행 상황
```

## 일의 흐름

1. **지시** — 본사에서 한 줄로 지시합니다.
2. **기획** — 기획 담당(Codex, 읽기 전용)이 작업 카드를 최대 8개 제안 → CEO가 고르고 승인합니다.
3. **구현** — 개발 담당(Codex)이 작업별 git worktree에서 허용된 경로만 고칩니다. 범위 밖 변경은 자동으로 되돌립니다.
4. **신뢰 검증** — 후보 커밋을 깨끗한 폴더로 꺼내 `trusted/`의 테스트를 돌립니다. 실패하면 피드백을 붙여 1번 더 시도합니다.
5. **리뷰** — 리뷰 담당(Claude Code, 읽기 전용)이 변경을 검토합니다.
6. **결재** — CEO가 검증·리뷰·diff를 보고 승인하면, 검증한 그 커밋만 main에 병합합니다.

자세한 규칙: [company/handbook.md](company/handbook.md)

## 명령

| 명령 | 설명 |
|---|---|
| `python studio.py serve` | 대시보드와 작업자 실행 (Ctrl+C로 종료) |
| `python studio.py doctor` | 점검 결과를 터미널에 출력 |
| `python studio.py init` | 제품 저장소·첫 작업 준비 (여러 번 실행해도 안전) |
| `python studio.py selftest core-courier` | 신뢰 테스트가 일부러 망가뜨린 구현을 잡아내는지 확인 |
| `python studio.py status` | 작업 목록 출력 |
| `python -m unittest discover -s tests` | 감독 프로그램 자체 테스트 |

## 문제가 생기면

- **막힘: 로그인 필요** — 터미널에서 `codex login` 또는 `claude auth login`으로 직접 로그인한 뒤 재시도.
- **막힘: 구독 사용 한도** — 회사가 자동 정지됩니다. 한도가 풀리면 재개 → 재시도. API로 우회하지 않습니다.
- **감독 프로그램이 이미 실행 중** — 다른 창의 `serve`를 먼저 끄세요.
- 실행별 프롬프트·로그: `data/runs/<실행ID>/`, 검증 증거: `data/qa/<검증ID>/evidence.json`
