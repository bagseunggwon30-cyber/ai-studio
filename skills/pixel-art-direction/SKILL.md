### 먼저 글로 정하고 시작 (네 가지)
1. 그림 크기(가로×세로 px): 화면 해상도에 맞춘다 (예: 640×360 화면의 캐릭터는 16×16 또는 24×24). 확대는 정수배(2·3·4배)만, 부드럽게 늘리는 필터는 끈다 (Godot 텍스처 필터는 Nearest).
2. 팔레트: 전체 16~32색 이하, 그림 하나는 4~8색. 색을 먼저 정하고 그 색만 쓴다. `design-kit`의 `palette`로 만들고 `image_info`로 실제 색 개수를 센다.
3. 빛 방향은 한쪽으로 (예: 왼쪽 위). 밝은색·기본색·어두운색 3톤으로 입체를 낸다.
4. 외곽선을 쓰면 1px, 색은 검정 대신 어두운 같은 계열. 한 세트는 모두 같은 규칙.

### 그릴 때
- 반투명 픽셀은 쓰지 않는다 (알파 0 또는 255). 가장자리를 부드럽게 흐리지 않는다. `image_info`의 반투명 비율이 0%에 가까워야 한다.
- 격자에 맞춘다. 회전이나 소수 배율로 뭉개지 않는다. 대각선은 일정한 계단(1:1, 2:1)으로.
- 실루엣이 먼저다: 검게 칠해도 무엇인지 알아봐야 한다. 구별해야 하는 것(플레이어·적·코어·출구)은 색 계열·모양(원·네모·삼각)·크기가 모두 달라야 한다.
- 배경은 어둡고 채도를 낮게, 움직이는 것과 눌러야 할 것은 밝고 채도를 높게 — 눈이 갈 곳이 튀게 한다.
- 캐릭터는 CEO의 그림 기준을 따른다: 자연스러운 성인 체형, 일상 옷. 과장된 체형이나 노출 옷은 그리지 않는다.

### 움직임
- 프레임은 적게: 걷기 4, 대기 2, 피격 1~2. 프레임 사이 이동은 1~2px.
- 움직임은 멋이 아니라 알림이다. 상태가 바뀌는 순간에 크게 움직이고 평소에는 조용하게.

### 파일
- 파일 이름은 소문자·숫자·밑줄만, 크기와 프레임 수를 이름이나 옆 메모에 적는다 (예: `player_16.png`). 시트는 프레임 크기 고정, 간격 0.
- 새 그림을 제품에 넣기 전에 출처를 구분해 보고한다: 직접 그린 것 / 생성한 것 / 가져온 것. 가져온 것은 `THIRD_PARTY_NOTICES.md`에 적을 수 있게 출처와 라이선스를 남기고, 임의로 내려받지 않는다.

### 마치기 전 확인
- 색 개수·크기·반투명 비율을 `image_info`로 쟀는가 / 실제 화면 배율에서 가장 작게 보일 때도 구별되는가 / 배경 위에서 대비가 충분한가.
